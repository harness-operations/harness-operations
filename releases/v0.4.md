# Harness Operations Reference Model 0.4

Reference Model 0.4 adds **Code Mode** as a generic, cross-cutting tool-use pattern in the Standards Landscape.

## Added

- A vendor-neutral definition of Code Mode: model-written programs compose tool/API calls and handle intermediate results without requiring another model inference per operation.
- Historical attribution to Cloudflare's September 26, 2025 public Code Mode framing, with earlier code-as-action research such as CodeAct (2024) distinguished from that named introduction.
- Documentation-backed implementation examples across different execution surfaces: Cloudflare, Goose, Anthropic programmatic tool calling, and FastMCP. Sharing the pattern's name does not imply a common protocol, interchangeable semantics, or adoption by every surface from a provider.
- Explicit operational guidance for authority and policy on nested calls; program/runtime identity; per-operation evidence and limits; credential handling; cancellation, partial completion, reconciliation, and safe retry.
- Comparison methodology clarifying that Code Mode is a characteristic of a scoped implementation, **not** a product row or automatic compatibility badge.

## Evidence and limitations

These are **documentation-backed landscape and methodology additions**. Version-scoped product capability observations, existing live-test results, and directed compatibility findings have **not** been upgraded or re-tested for Code Mode.

Cloudflare and other named projects illustrate their own documented execution surfaces; no universal sandboxing, approval, determinism, performance, replay, or exactly-once guarantee is asserted for Code Mode.

Existing landscape sources retain their earlier verification dates; the new Code Mode section was reviewed September 30, 2026.

## Unchanged

- No new Harness Operations wire protocol, mandatory Code Mode primitive, shared executor requirement, registry, conformance program, or certification.
- The foundational reference-model concepts, three v0.3 operational patterns, executable handoff fixture, and existing seven-system comparison rows remain substantively unchanged.
- Previously recorded lack of qualifying independent external reproduction remains disclosed; this release does not claim external endorsement.
