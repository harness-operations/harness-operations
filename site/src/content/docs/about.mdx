Harness Operations helps you learn what AI-agent capabilities exist, understand
trade-offs, and find tools worth investigating for your goals.

## A guide, not an architecture

There is no required set of components, maturity ladder, or universal best tool.
Applications, agent harnesses, tool interfaces, and runtimes can all be useful,
but they are not interchangeable. We explain the differences without requiring
you to learn a taxonomy before you can start.

[Explore capabilities](/capabilities/), [browse tools](/systems/), or
[use the guided chooser](/choose/).

## What the evidence means

Entries record an exact reviewed interface, version or revision where available,
review date, source material, and limitations. Reading documentation or source
code does not establish a live integration test. A feature count does not measure
product quality, model quality, or how well a tool will work for your task.

The chooser filters explicit fields in the [Systems index](/systems/index.json).
It does not assign scores, infer private/offline operation from a local interface,
or claim that missing catalog coverage means no suitable products exist.
Its answers remain in the page; it makes no model calls and adds no persistence.

[Read the comparison methodology](/apply/comparison-methodology/).
